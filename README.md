# Brand Iso — Claude Code Skill Pack

## What is this?
A Claude Code skill that generates brand-matched isometric illustrations from your brand guidelines.
- Extracts brand colors, fonts, and style from your input
- Generates isometric SVG illustrations using 30° grid system
- Auto-adapts to dark/light mode
- No external dependencies (pure inline SVG)

## How to install
```bash
npx skills add https://github.com/JJohnHee/brand-iso
# Or manual
cp -r brand-iso ~/.claude/skills/
```

## How to use
Open Claude Code and say:
> "Our brand color is #4F46E5. Generate an isometric illustration of an AI agent workflow."

You'll get:
- Complete SVG code (copy-paste ready)
- Dark/light mode CSS
- Brand-matched colors (60% primary / 30% secondary / 10% accent)

## What you get
- 4 isometric component templates (server/cloud/person/gear)
- Brand color extraction system

- Auto dark/light mode
- SVG output (scalable, editable, no external assets)
